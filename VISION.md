# Origin Vision

## Mission

Build the best desktop companion for developers.

Origin should reduce context switching, surface useful information, and help developers stay focused while building software.

---

# Philosophy

Origin is not an IDE.

Origin is not a Git client.

Origin is not a project launcher.

Origin complements the tools developers already use.

Instead of replacing VS Code, Cursor, or IntelliJ, Origin enhances the development experience around them.

---

# Long-Term Vision

The centerpiece of Origin is the Origin Overlay.

A lightweight interface that can be opened instantly from anywhere.

Eventually the overlay will include:

- Active Project
- Git Status
- Project Health
- TODOs
- README
- Notes
- AI Assistant
- Terminal
- Spotify
- Recent Files
- Session History

The goal is to make Origin feel like a second brain for developers.

---

# Core Principles

## Reduce Context Switching

Developers should spend more time building and less time navigating tools.

---

## Surface Useful Information

Origin should proactively present important information instead of waiting for users to search for it.

---

## Respect Existing Workflows

Origin should work with existing editors rather than replacing them.

---

## Stay Lightweight

Fast startup.

Fast interactions.

Minimal distractions.

---

# Every Feature Must Answer

Does this make Origin a better developer companion?
